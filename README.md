**NexusAI** is a daily-utility **Visual AI Personal Assistant, Multi-Engine Live Search Hub, Interactive Engineering Lab (`EngiLab`), and Productivity Co-Pilot** built for engineers, students, and young tech professionals.

🌐 **Try Live Now (Android PWA & Web):** **[https://kiran10299.github.io/nexus-ai.html](https://kiran10299.github.io/nexus-ai.html)**

---

## ✨ Key Features

1. **🧠 Visual AI Personal Assistant (Dual Engine + Generative UI Widgets)**
   - **Works Out-of-the-Box (Zero API Key Required):** Powered by free cloud LLM inference + optionally supports **Google Gemini 2.0 Flash API** (`AIza...` key).
   - **Inline Generative Visual Cards:** Automatically renders interactive **Signal & Harmonic FFT Oscilloscopes**, **4–20mA PLC Loop Gauges**, **LabVIEW DQMH / System Architecture Diagrams**, **AI Blueprint Renders**, and **Live Search Knowledge Cards** directly inside chat responses.
   - **Voice Input & Neural Voice TTS:** Speak questions hands-free via microphone and hear spoken answers.

2. **🔍 Multi-Engine Visual Search Hub**
   - Queries **Wikipedia REST Knowledge Graph**, **GitHub Open-Source Repositories**, and **AI Visual Concept Blueprints** in parallel with rich visual cards, star counts, and 1-tap AI synthesis.

3. **🛠️ EngiLab — Daily Engineering Calculators**
   - **4–20 mA PLC Current Loop Scaler** with live 16-bit ADC counts and visual progress bar.
   - **Ohm's Law & DC Power Dissociation Calculator**.
   - **RC Low-Pass Filter Cutoff Frequency ($f_c$) & Time Constant ($\tau$) Designer**.
   - **Universal Engineering Unit & Hex/Binary/Modbus Converter** (`bar/PSI/MPa`, `°C/°F/K`, `Nm/lb-ft`, `RPM/Hz/rad/s`, `16-bit HEX/BIN`).

4. **🚀 Youth Daily Pulse — Focus, Habits & Smart Study Planner**
   - **Pomodoro Deep-Work Timer** (`25m Focus`, `50m Deep Engineering`, `5m Break`).
   - **Daily Habit & Hydration Tracker** (Water counter + coding/reading/ergonomic streaks).
   - **AI Smart Task & Study Planner** with 1-click *"AI Auto-Plan My Day"*.

## 📲 Install on Android

- **Option 1 — Instant Android Install (PWA):** Open **[https://kiran10299.github.io/nexus-ai.html](https://kiran10299.github.io/nexus-ai.html)** in Chrome on Android and tap **"Install App"** in the top bar (or *Add to Home Screen*).
- **Option 2 — Native Android APK:** Download `NexusAI-Android-APK` (`app-debug.apk`) from the **[GitHub Actions Artifacts](https://github.com/kiran10299/NexusAI-Android-Assistant/actions)** tab or build locally with `gradle assembleDebug`.
